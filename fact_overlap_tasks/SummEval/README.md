
# Downstream Task: SummEval

This folder includes the codes for reproducing the results on SummEval. 

The result is obtained by mapping the scores obtained on AggreFact Task because all the SummEval entries are included in AggreFact. 

If you want to obtain the result reported in the paper, please run the following code:

    python3 summeval_correlation_levels.py

The code of this folder is modified from the paper [Is ChatGPT a Good NLG Evaluator? A Preliminary Study](https://aclanthology.org/2023.newsum-1.1/) (Wang et al., NewSum 2023)
