# FDSpotter: Structured Discourse Representation for Factual Consistency Verification

This is the official github repo for the paper "FDSpotter: Structured Discourse Representation for Factual Consistency Verification" in Findings of ACL 2025. 

- [Paper (Findings of ACL 2025)](https://aclanthology.org/2025.findings-acl.46/)
- [FDSpotter model on Hugging Face](https://huggingface.co/Inria-CEDAR/FDSpotter-DeBERTa-V3-Large)
- [WebNLG training data and GPT-4o extraction outputs on Hugging Face](https://huggingface.co/datasets/Inria-CEDAR/FDSpotter)

- Summeval ✅ in ./fact_overlap_tasks/SummEval
- WebNLG eval ✅ in ./fact_overlap_tasks/SummEval
- DiverSumm ✅ in ./fact_overlap_tasks/Diversumm
